根据数据类自动生成存档代码是Unity中大型项目的标准做法。这里提供一个**基于反射+代码生成**的完整方案，支持自动识别标记字段、生成强类型存档代码、处理版本兼容。

## 核心架构

```
1. [Savable] 属性标记需要存档的字段
2. Editor工具扫描程序集，反射解析数据类结构  
3. 基于TextTemplate生成强类型 Save/Load/Reset 代码
4. 生成的 partial class 扩展原始数据类，提供 Archive() / Restore() 方法
```

## 完整实现

### 1. 核心属性定义 (Runtime)

```csharp
// SavableAttribute.cs
using System;

[AttributeUsage(AttributeTargets.Field | AttributeTargets.Property)]
public class SavableAttribute : Attribute 
{
    public string Key { get; set; }        // 自定义存档键名（可选）
    public object DefaultValue { get; set; } // 默认值（可选）
    public bool Encrypt { get; set; }      // 是否加密存储
}

// 标记类需要生成存档代码
[AttributeUsage(AttributeTargets.Class)]
public class AutoArchiveAttribute : Attribute 
{
    public int Version { get; set; } = 1;  // 存档版本号，用于迁移
}
```

### 2. 代码生成模板 (Editor)

```csharp
// Editor/ArchiveCodeGenerator.cs
using UnityEngine;
using UnityEditor;
using System;
using System.IO;
using System.Text;
using System.Collections.Generic;
using System.Reflection;

public static class ArchiveCodeGenerator 
{
    private const string OUTPUT_PATH = "Assets/Generated/Archive/";
    
    [MenuItem("Tools/Archive/Generate All")]
    public static void GenerateAll()
    {
        if (!Directory.Exists(OUTPUT_PATH))
            Directory.CreateDirectory(OUTPUT_PATH);

        int generatedCount = 0;
        
        // 扫描所有程序集
        foreach (var assembly in AppDomain.CurrentDomain.GetAssemblies())
        {
            foreach (var type in assembly.GetTypes())
            {
                if (type.GetCustomAttribute<AutoArchiveAttribute>() != null && !type.IsAbstract)
                {
                    GenerateForType(type);
                    generatedCount++;
                }
            }
        }
        
        AssetDatabase.Refresh();
        Debug.Log($"[ArchiveGenerator] 生成完成: {generatedCount} 个类");
    }

    private static void GenerateForType(Type dataType)
    {
        var className = dataType.Name;
        var nameSpace = dataType.Namespace ?? "GameData";
        var fullName = $"{nameSpace}.{className}";
        
        // 收集所有标记[Savable]的成员
        var members = new List<MemberInfo>();
        members.AddRange(dataType.GetFields(BindingFlags.Public | BindingFlags.NonPublic | BindingFlags.Instance));
        members.AddRange(dataType.GetProperties(BindingFlags.Public | BindingFlags.NonPublic | BindingFlags.Instance));
        
        var savableMembers = new List<(MemberInfo member, SavableAttribute attr, string key, string typeName)>();
        
        foreach (var member in members)
        {
            var attr = member.GetCustomAttribute<SavableAttribute>();
            if (attr == null) continue;
            
            string key = string.IsNullOrEmpty(attr.Key) ? member.Name : attr.Key;
            string typeName = GetTypeName(member);
            
            savableMembers.Add((member, attr, key, typeName));
        }

        if (savableMembers.Count == 0) return;

        // 构建代码
        StringBuilder sb = new StringBuilder();
        sb.AppendLine("// <auto-generated>");
        sb.AppendLine("// 自动生成的存档代码，请勿手动修改");
        sb.AppendLine("// </auto-generated>");
        sb.AppendLine();
        sb.AppendLine($"using UnityEngine;");
        sb.AppendLine($"using System.Collections.Generic;");
        sb.AppendLine();
        sb.AppendLine($"namespace {nameSpace}");
        sb.AppendLine($"{{");
        sb.AppendLine($"    public partial class {className}");
        sb.AppendLine($"    {{");
        
        // 生成存档数据结构
        sb.AppendLine($"        [System.Serializable]");
        sb.AppendLine($"        public class ArchiveData");
        sb.AppendLine($"        {{");
        sb.AppendLine($"            public int _version = {dataType.GetCustomAttribute<AutoArchiveAttribute>().Version};");
        
        foreach (var item in savableMembers)
        {
            string fieldType = item.member is FieldInfo fi 
                ? GetSerializableTypeName(fi.FieldType) 
                : GetSerializableTypeName(((PropertyInfo)item.member).PropertyType);
            
            sb.AppendLine($"            public {fieldType} {item.key};");
        }
        sb.AppendLine($"        }}");
        sb.AppendLine();

        // Archive() 方法
        sb.AppendLine($"        public ArchiveData Archive()");
        sb.AppendLine($"        {{");
        sb.AppendLine($"            var data = new ArchiveData();");
        
        foreach (var item in savableMembers)
        {
            string accessCode = GetMemberAccessCode(item.member, "this");
            if (item.attr.Encrypt)
            {
                sb.AppendLine($"            data.{item.key} = EncryptValue({accessCode});");
            }
            else
            {
                sb.AppendLine($"            data.{item.key} = {accessCode};");
            }
        }
        sb.AppendLine($"            return data;");
        sb.AppendLine($"        }}");
        sb.AppendLine();

        // Restore() 方法
        sb.AppendLine($"        public void Restore(ArchiveData data)");
        sb.AppendLine($"        {{");
        sb.AppendLine($"            if (data == null) return;");
        sb.AppendLine($"            ");
        sb.AppendLine($"            // 版本检查与迁移");
        sb.AppendLine($"            if (data._version < {dataType.GetCustomAttribute<AutoArchiveAttribute>().Version})");
        sb.AppendLine($"            {{");
        sb.AppendLine($"                MigrateFromOldVersion(data);");
        sb.AppendLine($"            }}");
        sb.AppendLine();
        
        foreach (var item in savableMembers)
        {
            string setCode = GetMemberSetCode(item.member, "this");
            string valueCode = item.attr.Encrypt 
                ? $"DecryptValue<{item.typeName}>(data.{item.key})" 
                : $"data.{item.key}";
            
            // 处理默认值
            if (item.attr.DefaultValue != null)
            {
                sb.AppendLine($"            {setCode}(data.{item.key} != null ? {valueCode} : {FormatDefaultValue(item.attr.DefaultValue)});");
            }
            else
            {
                sb.AppendLine($"            {setCode}({valueCode});");
            }
        }
        sb.AppendLine($"            OnRestored?.Invoke();");
        sb.AppendLine($"        }}");
        sb.AppendLine();

        // 重置方法
        sb.AppendLine($"        public void ResetToDefault()");
        sb.AppendLine($"        {{");
        foreach (var item in savableMembers)
        {
            if (item.attr.DefaultValue != null)
            {
                string setCode = GetMemberSetCode(item.member, "this");
                sb.AppendLine($"            {setCode}({FormatDefaultValue(item.attr.DefaultValue)});");
            }
        }
        sb.AppendLine($"        }}");
        sb.AppendLine();

        // 事件与回调
        sb.AppendLine($"        public System.Action OnRestored;");
        sb.AppendLine();
        
        // 迁移虚方法
        sb.AppendLine($"        partial void MigrateFromOldVersion(ArchiveData data);");
        
        // 加密辅助（如果用到）
        bool hasEncryption = savableMembers.Exists(x => x.attr.Encrypt);
        if (hasEncryption)
        {
            sb.AppendLine();
            sb.AppendLine($"        private T EncryptValue<T>(T value) => value; // 接入你的加密系统");
            sb.AppendLine($"        private T DecryptValue<T>(object value) => (T)value;");
        }

        sb.AppendLine($"    }}");
        sb.AppendLine($"}}");

        // 写入文件
        string fileName = $"{className}.Archive.gen.cs";
        File.WriteAllText(Path.Combine(OUTPUT_PATH, fileName), sb.ToString());
    }

    // 辅助方法：获取成员访问代码
    private static string GetMemberAccessCode(MemberInfo member, string instance)
    {
        if (member is FieldInfo)
            return $"{instance}.{member.Name}";
        else
            return $"{instance}.{member.Name}";
    }

    private static string GetMemberSetCode(MemberInfo member, string instance)
    {
        if (member is FieldInfo)
            return $"({instance}.{member.Name} = ";
        else
            return $"{instance}.{member.Name} = ";
    }

    private static string GetTypeName(MemberInfo member)
    {
        Type type = member is FieldInfo fi ? fi.FieldType : ((PropertyInfo)member).PropertyType;
        return type.Name;
    }

    private static string GetSerializableTypeName(Type type)
    {
        if (type == typeof(int)) return "int";
        if (type == typeof(float)) return "float";
        if (type == typeof(string)) return "string";
        if (type == typeof(bool)) return "bool";
        if (type == typeof(Vector2)) return "Vector2";
        if (type == typeof(Vector3)) return "Vector3";
        if (type.IsGenericType && type.GetGenericTypeDefinition() == typeof(List<>))
            return $"List<{GetSerializableTypeName(type.GetGenericArguments()[0])}>";
        if (type.IsArray)
            return $"{GetSerializableTypeName(type.GetElementType())}[]";
        return type.FullName;
    }

    private static string FormatDefaultValue(object value)
    {
        if (value is string s) return $"\"{s}\"";
        if (value is bool b) return b.ToString().ToLower();
        return value.ToString();
    }
}
```

### 3. 存档管理器 (统一IO接口)

```csharp
// ArchiveSystem.cs (Runtime)
using UnityEngine;
using System.IO;
using System.Collections.Generic;

public static class ArchiveSystem 
{
    private static string SavePath => Application.persistentDataPath + "/SaveData/";
    
    public static void Save<T>(string slotId, T data) where T : class
    {
        if (!Directory.Exists(SavePath)) Directory.CreateDirectory(SavePath);
        
        var json = JsonUtility.ToJson(data, true);
        // 可选：加密 json
        File.WriteAllText(GetFilePath(slotId), json);
    }

    public static T Load<T>(string slotId) where T : class
    {
        string path = GetFilePath(slotId);
        if (!File.Exists(path)) return null;
        
        string json = File.ReadAllText(path);
        // 可选：解密
        return JsonUtility.FromJson<T>(json);
    }

    public static void Delete(string slotId)
    {
        string path = GetFilePath(slotId);
        if (File.Exists(path)) File.Delete(path);
    }

    private static string GetFilePath(string slotId) => $"{SavePath}{slotId}.json";
}
```

```csharp
using UnityEngine;

namespace GameData
{
    [AutoArchive(Version = 2)]  // 标记为自动存档，当前版本2
    public partial class PlayerData

        [Savable] 
        public int Level;

        partial void MigrateFromOldVersion(ArchiveData data)
        {
            if (data._version == 1)
            {
                // 从旧版本升级：比如重命名字段
                // data.NewField = data.OldField;
            }
        }
    }
}
```

### 业务代码使用

```csharp
public class PlayerManager : MonoBehaviour 
{
    public PlayerData Data { get; private set; } = new PlayerData();
    
    private const string SAVE_SLOT = "player_main";
    
    void Start()
    {
        LoadGame();
    }
    
    void OnApplicationQuit()
    {
        SaveGame();
    }
    
    public void SaveGame()
    {
        // 调用生成的 Archive() 方法
        var archive = Data.Archive();
        ArchiveSystem.Save(SAVE_SLOT, archive);
        Debug.Log($"存档成功: Level={archive.Level}");
    }
    
    public void LoadGame()
    {
        var archive = ArchiveSystem.Load<PlayerData.ArchiveData>(SAVE_SLOT);
        if (archive != null)
        {
            Data.Restore(archive);
            Debug.Log($"读档成功: Level={Data.Level}");
        }
        else
        {
            Data.ResetToDefault(); // 新玩家
        }
    }
    
    [ContextMenu("手动存档")]
    void ManualSave() => SaveGame();
}
```

## 高级扩展

### 1. 复杂类型支持（Dictionary等）

Unity的JsonUtility不支持Dictionary，生成器可自动转换为可序列化结构：

```csharp
// 在代码生成器中添加特殊处理
if (type.IsGenericType && type.GetGenericTypeDefinition() == typeof(Dictionary<,>))
{
    // 生成 List<SerializableKeyValuePair> 替代
    sb.AppendLine($"            public List<SerializableKV<{keyType},{valueType}>> {item.key};");
}
```

### 2. 增量保存（Dirty标记）

生成代码中自动加入脏标记，只保存变更数据：

```csharp
[Savable] 
public int Gold 
{ 
    get => _gold; 
    set { _gold = value; IsDirty = true; } 
}
```

### 3. 多存档槽位与元数据

```csharp
public class ArchiveMeta 
{
    public string SlotId;
    public System.DateTime SaveTime;
    public string PreviewText; // "Level 20 - 2026.01.31"
    public Texture2D Screenshot;
}
```

### 4. 与苏菲炼金工坊式存档结合

如果需要类似炼金工房的**物品栏+配方解锁**存档结构：

```csharp
[AutoArchive]
public partial class AlchemyData 
{
    [Savable] public List<int> UnlockedRecipeIds;  // 解锁配方ID
    [Savable] public Dictionary<int, int> MaterialStorage; // 材料库存
    [Savable] public SerializableDictionary<string, ContainerData> BoxStorage; // 各容器存储
}
```

生成后的代码会自动处理 Dictionary 的序列化转换。

## 工作流程

1. **编写数据类** → 标记 `[AutoArchive]` 和 `[Savable]`
2. **菜单生成** → `Tools/Archive/Generate All`  
3. **业务调用** → `data.Archive()` / `data.Restore(archive)`
4. **版本升级** → 修改 `Version = 3`，在partial方法中写迁移逻辑

这套方案避免了反射带来的运行时性能损耗（生成的是硬编码代码），同时保持了类型安全和版本兼容。
